# Image reveal animation using GSAP ScrollTrigger

A Pen created on CodePen.

Original URL: [https://codepen.io/erichologist/pen/jErjZeK](https://codepen.io/erichologist/pen/jErjZeK).

This is an improved version of my previous reveal example. In this I removed clip-path animation and replaced with transform animations to maximise performance. We are also taking advantage of GSAP's ScrollTrigger plugin which is more accurate than my previous example on larger projects.
